# Credit Card Fraud Detection Using Machine Learning

## Introduction

Credit card fraud is a major problem in the financial sector. This project uses machine learning techniques to detect fraudulent credit card transactions.

## Objective

The main objective of this project is to build a machine learning model that can classify credit card transactions as legitimate or fraudulent.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Imbalanced-learn
- SMOTE

## Machine Learning Techniques

The project includes data preprocessing, exploratory data analysis, feature analysis, handling class imbalance using SMOTE, and machine learning model comparison.

## Project Files

- `credit.py` – Main Python source code
- `fraud_model.pkl` – Trained machine learning model
- `model_comparison.csv` – Model comparison results
- `eda_plots.png` – Exploratory data analysis plots
- `feature_importance.png` – Feature importance visualization
- `roc_curves.png` – ROC curve results

## Dataset

The dataset contains credit card transaction information used for identifying fraudulent transactions.

## Results

The performance of the machine learning models was evaluated using metrics such as:

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC

## Conclusion

This project demonstrates how machine learning can be used to identify potentially fraudulent credit card transactions and support fraud detection systems.
